# PromptKar 🚀

**PromptKar** is a premium, high-performance social platform and directory for AI prompt engineering. Built with **Next.js 15 (Turbopack)**, **Tailwind CSS**, **MongoDB**, and **Firebase**, it empowers creators to discover, share, and improve AI prompts using state-of-the-art Gemini AI.

## ✨ Key Features

- **Prompt Directory**: Explore high-quality prompts for Midjourney, ChatGPT, Claude, and more.
- **AI Enhancer**: Transform basic prompts into detailed, effective instructions using the Gemini 1.5/2.0/3.0 engine.
- **Social Ecosystem**: Like, save, and follow your favorite prompt engineers.
- **Live Notifications**: Real-time engagement alerts powered by Pusher.
- **Premium UI**: A sleek, "Cyber-Luxe" aesthetic with a full-screen mobile navigation system.
- **Admin Hub**: A secure command center for platform management, blog publishing, and live settings sync.

## 🛠️ Technology Stack

- **Framework**: Next.js (App Router)
- **Database**: MongoDB (Mongoose)
- **Auth**: Firebase Authentication
- **AI**: Google Gemini AI SDK
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Real-time**: Pusher Channels

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment**:
   Create a `.env.local` file with the following keys:
   - `MONGODB_URI`
   - `NEXT_PUBLIC_FIREBASE_CONFIG`
   - `GEMINI_API_KEY`
   - `PUSHER_APP_ID`, `PUSHER_KEY`, `PUSHER_SECRET`

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

4. **Access the Platform**:
   Open [http://localhost:3000](http://localhost:3000) in your browser.
